# Contributing

Thank you for looking. This repository is a published artifact of the Agenthon 2026 competition:
people build against it, so a change here is not free for them.

## How changes reach this repository

1. Changes land through **pull requests**, so there is a written record of what changed and why.
2. Changes are **batched into planned releases** rather than pushed one at a time, because a push
   costs every entrant a re-check of whatever they were building against.
3. Releases are cut by the competition organizers.

## Reporting a problem

If a command this repository documents does not work, or a scored result looks wrong, please open an
issue. Those two cases are what we treat as urgent; everything else is batched into the next
scheduled release.
