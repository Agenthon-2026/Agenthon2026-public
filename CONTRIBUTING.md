# Contributing

Thank you for looking. This repository is a published artifact: participants install it and pin a
tag, so a push here is not free for them — it costs a re-pin, a re-verify, and, if scoring moved, a
recalibration of whatever they were optimising against.

## How changes reach this repository

1. Changes are **batched into planned releases** rather than pushed one at a time.
2. Every change is reviewed before it lands.
3. Releases are cut by the competition organizers.

## Reporting a problem

If a command this repository documents does not work, or a scored result looks wrong, please open an
issue. Those two cases are what we treat as urgent; everything else is batched into the next
scheduled release.
